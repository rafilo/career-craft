# Job-description tailoring

## Process

1. Identify the target role, level, domain, core responsibilities, mandatory
   capabilities, preferred capabilities, and behavioural signals.
2. Build a match table with `strong evidence`, `partial evidence`, `not evidenced`,
   and `not applicable`.
3. Reorder and rephrase supported evidence around the employer's priorities.
4. Preserve important transferable capability when exact domain experience is absent.
5. Flag genuine gaps; do not conceal them with copied keywords.

## Keyword policy

- Natural repetition is acceptable when a term is central to the role.
- Use the employer's canonical wording when it matches the candidate's evidence.
- Include synonyms where human readers benefit, not to game scoring systems.
- Never add a keyword solely because it appears frequently in the JD.

## Output

Provide:

1. Tailored resume content
2. Brief change summary
3. Evidence gaps or `[VERIFY]` questions
4. Optional keyword coverage table when requested
